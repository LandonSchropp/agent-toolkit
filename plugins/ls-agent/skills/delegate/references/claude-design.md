# Claude Design

Claude Design is a web product with no CLI, so the user carries the prompt over rather than an agent sending it.

Write the prompt, then print it as a fenced code block with nothing else competing for the message, and point the user at [Claude Design](https://claude.ai/design) to paste it into.

Because the user pastes it themselves, the prompt reads as them speaking. It takes no preamble about where it came from.

Two nearby tools are not this one: the bundled `design` skill is a smaller in-terminal preview, and `DesignSync` only pushes a component library into a design system that already exists.
