# Non-Engineering

Non-Engineering runs in Claude Desktop, where each domain has its own project that keeps the context and runs scheduled tasks.

## Sending

There's no automated route into Claude Desktop yet, so the user carries the prompt over. Write the prompt, then print it as a fenced code block with nothing else competing for the message, and name the Cowork project in Claude Desktop whose domain the task falls in. A one-off task with no matching project goes in a new conversation.

Because the user pastes it themselves, the prompt reads as them speaking. It takes no preamble about where it came from.
